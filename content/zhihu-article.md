# 知乎文章：如何禁止某个 Windows 程序联网，而不影响其他软件？

## 标题
如何禁止某个 Windows 程序联网，而不影响其他软件？

## 正文

### 问题背景

Windows 自带防火墙当然能做到，但操作路径深、规则配置复杂，普通人折腾十分钟也不一定配明白。第三方工具里，SimpleWall、TinyWall、Windows Firewall Control 都不错，但对"只想给某一个程序断网"这个需求来说，还是偏重了。

我做了个轻量工具 NetGate，专门解决这一个问题：**给单个程序断网，点一下，不影响系统和其他软件**。

### 它做什么

- 你指定一个 `.exe`，禁止或恢复它的联网（出站+入站）
- 你可以从"正在运行 + 已安装"的程序列表里点选，不用手打路径
- 可以把 `.exe` 直接拖进页面
- 支持暂停/恢复、批量勾选、配置导出导入

### 它不做什么

- 不内置任何软件名单，不针对任何厂商
- 不修改系统默认网络设置，不影响你没指定的程序
- 不破解、不绕过任何软件的授权机制
- 默认不收集任何数据

### 为什么敢让它改防火墙

这是很多人最关心的。三点：

1. **只加自己的规则**：所有规则带 `NG-` 前缀，不改任何已存在的规则
2. **完全可逆**：点"清除全部规则"只删 `NG-` 规则，系统和其他软件的设置原样不动；删掉工具目录即可卸载
3. **代码开源可审计**：纯 PowerShell + 一个 HTML 页面，无依赖、无第三方 SDK

隐私政策也在仓库里，默认不收集、不上传，匿名统计需要手动开启。

### 怎么用

1. 去 GitHub 搜 `jiucheng-lin/netgate`，在 Releases 下载 zip
2. 解压，双击 `START.bat`，UAC 弹窗点是
3. 浏览器打开 `http://127.0.0.1:8765`
4. 从列表选一个程序，点"禁止联网"

### 适用场景

- 某软件总在后台自动更新、偷跑流量
- 给孩子的具体某个程序设限，而不是整台机器断网
- 测试环境里隔离某个程序的网络访问
