三步上手

不用手打路径，不会命令行也能用

下载解压

下载 zip，解压到任意文件夹，双击 START.bat。

选一个程序

点「从列表选择」挑一个，或把 .exe 拖进页面。

点禁止联网

完成。随时可以暂停、恢复或解除。

为什么可以放心用

一个要管理员权限的工具，信任必须说清楚

  • 只加自己的规则：所有规则带 NG- 前缀，不改任何已存在的规则
  • 一键清除：只删 NG- 规则，系统和其他软件的防火墙设置原样不动
  • 完全可逆：删掉规则、删掉目录，机器上不留痕迹
  • 默认不联网收集：服务只监听 127.0.0.1；匿名统计默认关闭，要手动开启
  • 代码开源可审计：纯 PowerShell + 一个 HTML 页面，无依赖、无第三方 SDK
